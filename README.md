# echo-terminal-center

Центр управления и мониторинга системы в терминале для Linux.

## О приложении

echo-terminal-center объединяет мониторинг оборудования и задачи администрирования Linux в едином клавиатурном TUI-интерфейсе.
Утилита собирает данные о процессоре, памяти, дисках, сети, звуке, Bluetooth и питании, а также управляет службами systemd и пакетами.
Приложение запускается от обычного пользователя и запрашивает права root через sudo только для операций, изменяющих систему.

## Возможности

### Модули интерфейса (TUI)

1. Системная информация: сводка параметров оборудования, ядра, памяти и дисков.
2. Обновление пакетов: проверка и установка обновлений через системный менеджер (pacman, apt, dnf) и flatpak.
3. Очистка кэша: анализ и очистка кэша пакетов, системного журнала systemd и миниатюр.
4. Управление сервисами: статус системных служб systemd с перезапуском и остановкой.
5. Состояние дисков: таблица файловых систем и опрос SMART-статуса накопителей.
6. Сетевые подключения: сетевые интерфейсы, IP-адреса, маршруты и DNS-серверы.
7. Логи системы: просмотр журнала ошибок systemd (journalctl -p err).
8. Диагностика: датчики температуры, флаги ядра, использование swap и статус питания.
9. Bluetooth: состояние адаптера, список сопряженных и активных устройств с уровнем заряда, переключение питания и подключение.
10. Аудио: входные и выходные устройства pactl/wpctl, выбор устройства по умолчанию, громкость и mute.
11. Установка приложений: поиск и установка программ из репозиториев и flatpak, удаление установленных пакетов.
12. Питание: состояние батареи, переключение профилей powerprofilesctl и регулировка яркости экрана.

### Режимы командной строки (CLI)

- `echo-terminal`: запуск интерактивного интерфейса TUI.
- `echo-terminal fetch`: прямой вывод системной карточки в терминал без TUI.
- `echo-terminal --json`: вывод метрик в формате JSON для скриптов.
- `echo-terminal --short`: краткая однострочная сводка параметров.
- `echo-terminal -h`, `--help`: справка по аргументам командной строки.
- `echo-terminal -V`, `--version`: версия программы.

## Установка

### Требования к сборке

- Компилятор Rust 1.75 или новее
- cargo

### Сборка из исходного кода

```bash
cargo build --release
```

Исполняемый файл создается по пути `target/release/echo-terminal`.

### Установка с помощью install.sh

```bash
./install.sh
```

Скрипт собирает release-версию, копирует исполняемый файл в `~/.local/bin/echo-terminal` и создает запись рабочего стола `~/.local/share/applications/echo-terminal.desktop`.

## Конфигурация

Приложение не требует внешних конфигурационных файлов. Язык интерфейса определяется автоматически по переменной окружения `LANG`:
- Значения, начинающиеся с `ru` (например, `ru_RU.UTF-8`), включают русский язык.
- Все остальные значения (включая `C` и `en_US.UTF-8`) используют английский язык.

Минимальный поддерживаемый размер окна терминала составляет 80x20 символов.

## Зависимости

### Библиотеки Rust (управляются Cargo)

- ratatui
- crossterm
- libc
- serde
- serde_json

### Системные утилиты (опциональные)

- pacman, apt или dnf: управление системными пакетами.
- flatpak: работа с пакетами Flatpak.
- systemd / journalctl: статус сервисов и чтение логов.
- pactl или wpctl: управление звуковыми устройствами.
- bluetoothctl: опрос и управление Bluetooth.
- smartctl: чтение SMART-статуса дисков.
- powerprofilesctl: профили энергопотребления.
- brightnessctl: регулировка яркости дисплея.

Если утилита не установлена в системе, соответствующий блок скрывается или показывает статус недоступности без аварийного завершения.
